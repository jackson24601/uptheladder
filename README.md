# Up the Ladder

A web-based classroom scoring game. Teams race up trees during a review. The first climber to the top wins — but every few minutes the wind may shake someone back down.

## Play

Open `index.html` in a browser (Chrome, Edge, Firefox, or Safari). For a projector, use **Fullscreen**.

1. Choose **2 to 6 teams**.
2. Name each team (optional). Each team’s climber wears a different color shirt.
3. Press **Start the climb**.
4. Tap **+** when a team earns a point. Ten rungs reach the apple at the top and win the game.
5. Tap **−** to send a team all the way back to the ground.
6. Every **three minutes**, a gust of wind shakes the trees and knocks **one random team** down a single rung. If that team is already on the ground, nothing happens to them.

Press **W** during a game to trigger a gust immediately (handy for a demo).

## Tips

- Use **Sound on/off** if the room does not want wind or climb sounds.
- **New game** returns to team setup.
- The game is a static page: no install, no server, and it works from a local file.
